# TechSparkX Client

React/TypeScript and Vite frontend for TechSparkX. The client package includes React Router and shared authentication/UI dependencies.

From this directory, run `npm install` and `npm run dev`. Use `npm run build` to build, `npm run lint` to lint, and `npm run preview` to inspect the build. Configure the API endpoint to match the server. The companion server and integration notes are in the repository-level [`README`](../README.md).
